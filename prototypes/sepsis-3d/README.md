# 《黃金一小時》3D 視覺試作

這個試作只回答一個問題（見 [`docs/PLAN-3D.md`](../../docs/PLAN-3D.md)）：

> **這款遊戲做得出 3D 自走棋的視覺感嗎？**

它只有「佈陣」和「自動處置」。商店、評估階段、院務事件和研究紀錄都還在 [2D 灰盒版](../sepsis-greybox/README.md)。

## 怎麼開

3D 版要透過網頁伺服器開啟（直接點兩下 `index.html` 會被瀏覽器擋下模型檔）：

```bash
npx serve prototypes/sepsis-3d
```

需要連網，three.js 是從 CDN 載入的。

有些靜態主機不提供 `.glb` 這種檔案類型。遊戲讀不到 `assets/models.glb` 時，會改讀同一份模型的文字編碼版 `assets/models.glb.b64.txt`，用下面的指令產生：

```bash
base64 -w0 prototypes/sepsis-3d/assets/models.glb > prototypes/sepsis-3d/assets/models.glb.b64.txt
```

## 怎麼玩

1. 下方是 10 位團隊成員。**點角色，再點棋盤上的格子**就能上場；也可以按數字鍵 1–8。
2. 格子上的編號是出手順序：第 n 位在第 15×n 分鐘第一次出手。前排青色格子在 60 分鐘內，後排沙色格子超過 60 分鐘。
3. 按「開始處置」看戰鬥。左側（手機在上方）的 Hour-1 bundle 元素會在實際執行的那一刻亮起。
4. 結算會列出各元素的執行時間和指引對照。可以「調整陣容再試」。

「建議陣容」會排好一組能控制住該回合的陣容。想看失敗的樣子，把抽血護理師或資深重症護理師換下來再打一次。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 版面和樣式 |
| `main.js` | 流程和介面（上方狀態列、羈絆面板、下方角色列、結算） |
| `stage.js` | 3D 舞台：棋盤、鏡頭、角色和敵人的動畫、戰鬥回放 |
| `presets.js` | 每回合的建議陣容 |
| `rules/data.js`、`rules/sim.js` | 遊戲規則。**和灰盒版完全相同的副本**，測試會檢查兩邊有沒有同步 |
| `assets/models.glb` | 所有 3D 模型，由 [`tools/blender/build_models.py`](../../tools/blender/README.md) 產生 |
| `assets.test.js` | 自動測試 |

規則只算出戰鬥的事件清單，3D 舞台照著播放，所以 3D 版和灰盒版的勝負一定相同。

## 測試

```bash
node --test prototypes/sepsis-3d/assets.test.js
```

- 規則檔和灰盒版相同
- 每個角色、每種敵人、每個場景道具都有模型，可動部位的名稱齊全
- 模型帶頂點色，檔案小於 2.5 MB
- 建議陣容每回合都控制得住（各跑 25 組隨機種子）

## 已知限制

- 沒有在真的手機上測過流暢度。
- 角色沒有骨架，動作是用程式移動頭、身體、雙手這幾個部位做出來的。
- 沒有音效。
- 同一個角色只能上場一次（羈絆本來就只算不重複的角色）。

> 教學用簡化模型，不能取代臨床判斷和院內 protocol。病例是虛構的，數值待臨床專家審閱。
