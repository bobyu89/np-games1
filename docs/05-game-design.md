# 遊戲企劃 v2：霧脈公會（2026-11-11 已確認）

> 2026-11-11｜這一版合併了三個來源：我們原本的企劃、你請 Codex 寫的《霧脈公會》規格書、衛福部公開的甄審規定。
> 世界觀、角色、主線和病例 C01 取自 Codex 那一份。標了「等你確認」的地方，是它和你之前的決定不一樣、需要你選的。
> 你在 2026-11-11 確認照第 12 節的建議做。下一步是風格定稿。

## 1. 一句話

> 你是霧脈公會的見習專科護理師。每位求診的人身旁都跟著一隻主訴化成的症影。你要在時限內做焦點式的問診和身體評估，把霧照散，向考官說明你的判斷，再向病人說明下一步。

世界是奇幻的，**臨床是真的**：要做的事和真的專科護理師一模一樣。

## 2. 不知道考題，怎麼設計

你不會提前知道題目，也不需要知道。**這個遊戲不猜題，練的是「拿到任何主訴都會做」的方法。**

### 2.1 官方公開的三樣東西

| 公開資料 | 寫了什麼 | 我們怎麼用 |
|---|---|---|
| [口試流程及評分方式](https://www.mohw.gov.tw/dl-102764-a11e5aa6-8a16-40b9-9bae-869a76ea7e5c.html) | 考什麼能力、時間、配分（見第 3 節） | 試煉的規則和評分照它做 |
| [筆試範圍](https://www.mohw.gov.tw/dl-101170-3557121c-a298-4241-87cc-dc68c39f9cad.html) | 內科、外科各涵蓋哪些系統 | 題庫要涵蓋這些系統 |
| 同一份文件的參考書目 | 指定的健康評估和內科教科書 | 病例內容的出處 |

筆試範圍列的系統：

- **內科**：心血管、胸腔與呼吸、肝膽腸胃、神經、內分泌、腎臟泌尿、肌肉骨骼、血液、免疫過敏與感染、腫瘤急症、生命末期照護；另有急重症和中毒。
- **外科**：術前評估與手術合併症、消化、內分泌、神經、泌尿、骨科、整形外科、五官外科；另有外科重症和創傷。
- **各科共同**：營養、體液電解質與酸鹼、發燒、感染。

### 2.2 題庫的做法

1. **用主訴當單位，照系統鋪開。** 每個主訴都牽涉好幾個系統，例如胸痛會碰到心血管、胸腔、腸胃、肌肉骨骼。選一批常見的主訴，讓上面的系統都被碰到。
2. **每個主訴至少三個病例**：示範案、同主訴但病因不同的變體、沒看過的遷移案。其中一定要有一個危險的、一個常見而不危險的。
3. **試煉用抽的，而且會抽到故事裡沒練過的主訴。** 真的考試就是進場前兩分鐘才知道主訴，試煉要還原這種不確定。
4. **每年的考試規則做成設定。** 時間、配分、提醒的時間點都不寫死，明年公告後改設定就好。
5. **不用考古題，不承諾命中考題。** 內容只用公開的規定和教科書。

### 2.3 候選的主訴（我的提案，要請臨床老師確認）

| 科 | 主訴 |
|---|---|
| 內科 | 胸痛、呼吸困難、腹痛、發燒、頭暈或暈厥、意識改變、水腫、頭痛、心悸、噁心嘔吐或腹瀉、解尿不適或血尿、關節痛或背痛、疲倦或體重減輕、咳嗽或咳血 |
| 外科 | 急性腹痛、術後發燒、傷口紅腫或滲液、肢體腫痛、摸到腫塊、創傷、解尿困難、肛門出血 |

### 2.4 任何主訴都適用的骨架

遊戲反覆練的就是這一套，提示一章一章拿掉。步驟取自官方的口試流程；先教察覺、再教解讀和回應、最後反思的順序，參考 Tanner（2006）的臨床判斷模式。

| 步驟 | 做什麼 |
|---|---|
| 閱題 | 讀病人資料和主訴。先想：最危險的可能是什麼、最常見的是什麼、我要問什麼 |
| 開場 | 自我介紹、確認病人、關心他現在的不舒服、說明接下來要做什麼 |
| 焦點病史 | 主訴的特徵 → 危險訊號 → 相關的過去病史、用藥與過敏、家族史、社會史 → 相關的系統回顧 |
| 焦點身體評估 | 先看生命徵象，再評估相關系統。每一項先向病人說明目的、項目和部位 |
| 向考官報告 | 最可能的健康問題和理由；還要排除什麼 |
| 向病人說明 | 評估的結果、下一步的計畫、要注意的事 |

## 3. 對齊甄審（115 年度的規定，已核對原文）

- 進考場前 2 分鐘，在門口讀病人基本資料和主訴。
- 站內 15 分鐘是一整段，結束前 3 分鐘廣播提醒，自己掌握時間。
- 進場後依主訴做**焦點式**病史訪談、焦點式健康評估、臨床推理與決策。
- 向口試委員解釋病人可能的健康問題和理由。
- 對病人解釋評估結果與下一步計畫或注意事項。
- 做身體評估時，同時向病人說明檢查目的、項目和部位。
- 配分：病史詢問與身體診察 50% 至 60%，鑑別診斷與臨床推理決策 40% 至 50%。
- 兩位口試委員評分，60 分及格。
- 簡章另外寫到：考場裡不能用自己帶的聽診器和筆燈；有發紀錄用紙，離場要繳回。

這是今年的規定。第一批玩家考的是明年，公告後要再核對一次。

## 4. 世界觀

### 4.1 一條規則

**地點、組織、角色的外觀可以奇幻；臨床的東西一律照真的。** 症狀、病史、身體評估的手法、診斷和檢查的名稱、生命徵象的數值和單位，一個字都不改。

### 4.2 霧港和症影

霧港依山傍海，有騎樓、雨棚、潮聲和公會的值班鐘。幾十年前，港城出現一種會凝結成形的霧。人在疼痛、喘不過氣、說不清自己怎麼了的時候，身旁有時會出現**症影**。霧脈公會把每一次照護的觀察記進圖鑑，幫下一位值班的人找到問對問題的起點。

- **症影跟著主訴，不跟著診斷。** 同一隻胸痛的症影會出現在不同的病例。牠長什麼樣子不會洩漏答案，病名由這個病例的證據決定。
- **霧代表「你還不知道的」。** 你拿到的資料越多，症影的輪廓越清楚。
- **病人的狀況不看症影**，看生命徵象、病人的反應和臨床資料。
- 病人有名字、有生活、有自己擔心的事。

## 5. 主線

| 章 | 發生什麼 | 玩家要學會的 |
|---|---|---|
| 序章　遺失的一頁 | 檔案室淹水，圖鑑只剩症影的外形。岑禾讓你接第一張委託 | 問、查、記錄；分清楚病人說的和量得到的 |
| 第一章　鐘聲之前 | 林秋想撐到交班，胸痛讓他停下來。街上另一個人也出現同一種症影 | 同樣的外形，比較病程和危險程度；早一點通報 |
| 第二章　同一張面孔 | 不同街區的人，把同一種症影叫成不同的名字 | 病人講法不同，也要問到同一個關鍵資訊 |
| 第三章　被蓋掉的紀錄 | 你找到公會舊的「一症一解」索引，重新追查被歸錯的委託 | 主動找反證，保留合理的不確定 |
| 終章　大霧值班夜 | 燈塔停電，兩張委託同時送到 | 排優先順序、交班、回頭重評 |
| 尾聲　新索引 | 圖鑑改寫成症狀、危險訊號、證據的索引 | 用一個沒看過的病例證明學會了 |

主線本身就在講「不要一個症狀只想到一個答案」。太早認定答案是診斷錯誤的常見來源（Croskerry, 2003）。

## 6. 一關怎麼玩

### 6.1 六種行動

| 行動 | 內容 |
|---|---|
| 問診 | 問一個焦點問題，病人照病例的劇本回答 |
| 評估 | 觀察、生命徵象、焦點身體評估。先向病人說明再做 |
| 檢查與資料 | 看已經有的資料，或提出要做的檢查 |
| 推理 | 寫一句問題摘要，排鑑別診斷，把線索標成支持、反對或待查 |
| 通報 | 呼叫支援、向值班醫師回報、重新評估 |
| 說明與結案 | 向病人說明，向考官或團隊提交摘要 |

- **急的事隨時可以做。** 第一步就可以呼叫支援，不用等問完。例如疑似急性冠心症要在 10 分鐘內取得並判讀心電圖（Rao et al., 2025），胸痛那一關不能等問診全部做完才做。
- **每個行動花掉一段模擬的時間**，例如問一題 30 秒。時間到了劇本上的點，病人的狀況會變，例如血壓掉下來。延遲了還有補救的機會。
- 重複問同一題拿到同樣的線索，分數只算一次。

### 6.2 兩種模式

| | 委託 | 資格試煉 |
|---|---|---|
| 樣子 | 有症影、有故事、有演出 | 中性的考場樣式，收起劇情和收藏 |
| 時間 | 模擬的時鐘，看字和操作選單不扣時間 | 閱題 2 分鐘，站內 15 分鐘的真實倒數，第 12 分鐘提醒 |
| 主訴 | 自己從委託板選 | 用抽的，可能沒練過 |
| 提示 | 岑禾會提示，圖鑑可以查 | 沒有 |
| 鑑別診斷 | 從清單選 | 第一版也從清單選，之後再加自己寫 |
| 回顧 | 每個階段都有 | 交卷後才有 |

之後再加第三種：刻意練習，只挑一種能力反覆練。

### 6.3 推理板

- 先寫一句問題摘要，例如「急性持續壓迫性胸痛合併冒冷汗」。
- 排出最可能的、最危險的、還要排除的。
- 每條線索可以連到好幾個假設，標成支持、反對或待查。
- 沒問到的、病人否認的、還不知道的，分開顯示。

### 6.4 關後回顧

1. **蒐集**：選一個影響判斷的時間點，看那一刻你知道什麼。
2. **分析**：比較你的做法、其他可以接受的做法、可能漏掉的關鍵。
3. **摘要**：寫下一個下次要做到的行動，帶進下一關。

回顧是模擬教學裡學習發生的地方（Fanning & Gaba, 2007）。

## 7. 評分

照官方的配分。試作的量尺共 100 分：

| 軌道 | 內容 |
|---|---|
| 資料收集與診察 55 | 焦點病史 25；生命徵象與焦點身體評估 20；取得同意與說明檢查 10 |
| 推理與決策 45 | 問題摘要和優先的鑑別 15；支持和反對的證據 10；照護、回報和重評 15；對病人說明 5 |

- 分數旁邊另外標**安全狀態**：達成、延遲補救、需要複核。
- 每一項量尺寫清楚看哪個行動、給幾分、有哪些可以接受的替代做法。同樣的操作一定得到同樣的分數。
- 遊戲的分數是訓練用的，不代表正式甄審的成績。

## 8. 開場和教學

- 不先給選單。雨打在燈匠的銅箱上，林秋靠著門框。岑禾把紀錄板交給你：「你現在最想知道什麼？有什麼要同時處理？」

## 10. 美術和技術

- **畫風：手繪繪本風（2026-11-12 定案）。** 平塗、鉛筆描邊、紙的顆粒、低彩度的綠和土黃。網頁介面負責文字、表單和推理板，做成紙片的樣子；上面一塊手繪風的平面場景負責病人、症影和演出。
  - 經過：先做了 3D 像素的定稿，你看過之後給了一組手繪繪本風的參考圖，同一個場景又做了一張繪本版來對照，你選了繪本版。兩張都留在 `prototypes/`。
  - 參考圖只當方向，沒有收進專案；角色、房間和構圖都是重新設計的。正式上線如果想要某位插畫家本人的味道，要找對方合作或授權。
  - 病人畫成人，不畫成動物：身體評估要看膚色、頸靜脈、水腫。可愛的部分放在症影和道具上。
- **技術**：前端 React 加 TypeScript。規則核心是純 TypeScript，不碰畫面，之後可以原封不動搬到伺服器。後端用什麼語言還沒定，見 [`04-system-design.md`](04-system-design.md) 最上面的說明。
- **和 CDSS 的關係**：照你之前定的，獨立，不連。

## 13. 之後補上的（2026-11-12）

試玩互動原型之後，你覺得要更有深度，並且確認了三件事。細節在 [`06-progression.md`](06-progression.md)。

| 項目 | 做法 |
|---|---|
| 解讀放進主迴圈 | 症影底下四盞燈是四個真身。拿到關鍵線索，玩家要選它讓哪一個更像或比較不像；選對霧才散。岑禾中途問一次「你最擔心哪一個」 |
| 同一隻症影、不同的真身 | 同一個主訴的病例共用同一套題目，只有病人的回答和真身不同 |
| 長期的蒐集 | 圖鑑只收玩家自己解讀對的線索；圖鑑寫到哪，故事走到哪 |
| 長度 | 一張委託約 10 分鐘 |
