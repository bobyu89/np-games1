# 歸航記：用《奧德賽》重新串起霧脈公會

2026-11-21 起草，同一天照這份做完（研究主持人：照建議做、一次做完，每一座島要有篇章）。實際做了什麼記在 `05-game-design.md` §28；第五節的幾件事都照建議定案：病人不改名、長老和忍冬用原名、遊戲名《霧脈公會：歸航記》、主角不綁性別、劫影的畫不重畫。原本分三階段，結果第一、二階段一起做了，第三階段（重畫劫影）沒有做。

---

## 一、核心：這不是換皮，是換一條脊椎

《奧德賽》講的是一件事：**一個人在海上被困了很久，一關一關地認出眼前的危險，最後回到家，把被佔據的家拿回來。**它的結構剛好有三段，跟我們已經做好的東西一一對得上：

| 《奧德賽》 | 霧脈公會現在的樣子 | 歸航記裡的樣子 |
|---|---|---|
| 第一到四卷：少年忒勒馬科斯在導師「門托」陪同下出海，去問老國王們父親的下落 | 序章、第一章：見習的你，岑禾帶著，報到 | **啟程**：你是剛出師的見習，導師帶你上船 |
| 第五到十二卷：漂流，一座島一個危險 | 第二到五章：四座外島、十二隻症影 | **漂流**：十二隻劫影，就是十二段海上的試煉 |
| 第十三到二十四卷：喬裝回家、拉弓之試、認出疤痕、重整家園 | 終章：大霧值班夜、燈塔、忍冬 | **歸航**：在大霧裡回到主島，點亮燈塔，通過十二斧之試 |

我們本來的主題是「一隻症影不會只有一個答案；寫的人、用的人、簽的人、收的人，每個人都只省了一步」。《奧德賽》剛好是一部**「認出來」的史詩**：奧德修斯每一關活下來，都是因為認出了眼前的東西不是它看起來的樣子；他回到家，也是靠老乳母洗腳時摸到那道疤，才被認出來。**「認出來」就是臨床推理**，所以這條脊椎不只是好看，它本身就是我們要教的東西。

## 二、世界觀：誰對到誰

### 霧和症影：普羅透斯的變形

《奧德賽》第四卷，海中老人普羅透斯會一直變形：變成獅子、蛇、豹、豬、水、樹。只要你抓住他不放，等他把所有形狀變完，他就會說出真話。

這就是症影的運作法則，而且比現在的設定更完整：

- 霧海的霧裡住著海中老人。人不舒服的時候，他會化成一種形狀浮在那個人身邊。港城的人都看得見，所以知道要來公會。
- 他化成的形狀只說「哪裡不舒服」，不說「為什麼」。你要問、要看、要量，一直抓著不放，他才會現出原形，也就是診斷。
- 所以**現在畫好的蛾、蛙、蟹、蜥……都不用重畫**：它們本來就是海中老人的變形。改的是名字和來歷：每一種變形，對到漂流途中的一段試煉，我們叫它「劫影」。

### 十二劫影：每一段試煉，就是那個主訴最容易掉進的陷阱

這是整個設計最重要的一張表。每一個主訴對到《奧德賽》的一段，而那一段在神話裡的危險，就是那個主訴在臨床上最典型的推理陷阱。玩家在回顧裡會被問：「這一劫，你有沒有被困住？」

| 主訴 | 現在的名字 | 劫影 | 神話裡發生什麼 | 對到的臨床陷阱 |
|---|---|---|---|---|
| 胸痛 | 胸悶蛾 | **獨眼巨人之劫** | 獨眼巨人只有一隻眼，只看得到一樣東西 | 只想到一個答案（心臟，或「只是肌肉」），沒有把四個方向都排過 |
| 喘 | 氣促蛙 | **風袋之劫** | 船員以為袋裡是金子，一打開，風把船吹回原點 | 處置打開得太早、太多（給氧、給點滴、給藥），沒先分清是哪一種喘 |
| 腹痛 | 腹痛蟹 | **斯庫拉之劫** | 六個頭的海怪守在窄道一側，只看一邊就會被另一邊吃掉 | 只盯著痛的那一點，沒問痛怎麼開始、怎麼移動 |
| 發燒 | 發熱蜥 | **日神之牛** | 船員餓了，忍不住吃了太陽神的牛，全船遭殃 | 燒還沒找到來源就先動手：加藥、換藥（「第三包藥」） |
| 頭痛 | 頭痛鳥 | **賽蓮之劫** | 熟悉、好聽的歌聲，讓水手駛向礁石 | 「老毛病」三個字太好聽：熟悉的說法讓你不再查紅旗 |
| 背痛 | 腰背龜 | **擲石巨人之劫** | 巨人從崖上扛起大石往下砸 | 扛著重量走來的人說「還撐得住」，你就信了 |
| 腳痛 | 跛足鷺 | **野豬之疤** | 老乳母洗腳時摸到少年時野豬留下的疤，才認出他 | 不脫鞋襪、不兩邊比，就看不到那道「疤」 |
| 腫脹 | 水腫豚 | **卡律布狄斯之劫** | 漩渦一天三次吞水又吐水 | 水從哪裡來：心、腎、肝三條路，只看腳腫就停 |
| 排泄物異常 | 二便獺 | **忘憂果之劫** | 吃了忘憂果的人，忘了要回家，也不想說 | 說不出口的事：你不問，他就不說 |
| 皮膚疹子 | 皮疹魷 | **喀耳刻之劫** | 女巫把人變成豬，外表變了，裡面還是那個人 | 以為皮膚的事就是皮膚的事，沒看疹子以外的地方 |
| 體重減輕 | 消瘦鼠 | **卡呂普索之劫** | 被留在島上七年，日漸消瘦，失去回家的念頭 | 「年紀大了、吃得少」：沒問他一個人的生活和心情 |
| 感覺異常 | 麻木鰻 | **冥府之劫** | 亡魂沒有知覺，你不先開口，他們不會說話 | 說不清楚的麻：不用手畫範圍、不問「最後一次正常」，就分不出是哪裡 |

這些陷阱名字**只出現在大廳、圖鑑和回顧**。病室裡照舊只講臨床的話，驗證器照舊會擋：病室和選項裡出現劫影的名字，`npm run cases` 就不會過。

### 十五年前的事：一場打完了、卻沒有人回得了家的仗

《奧德賽》的背景是特洛伊戰爭：仗打完了，每個人都帶著傷回家，很多人沒回到家。這就是我們的「四十天霧」：

- 十五年前，大潮淹了法羅斯，接著霧四十天沒有散，船出不去，人一直進來。歐律克勒亞（忍冬）寫了「一隻劫影一行字」的索引，救了很多人，也讓十一個人沒能回家。
- 那十一個名字，就是奧德修斯在冥府見到的亡魂。第十一個是埃爾佩諾（檜伯），那一行字是孟拓（岑禾）當見習時寫的。
- 長老會三比二決定不訂勘誤；費民（眠墨）拆了，沒有燒，用油布包好、鎖進鉛盒。
- 這些情節**全部照舊**，只換名字和說法。上一輪補好的三個漏洞（大潮不是巧合、鉛盒、誰看得見劫影）都保留。

### 歸航：終章怎麼收

史詩的最後三分之一是回家，我們的終章本來就在做這件事，現在只是把它說得更明白：

- **大霧值班夜**：燈熄了，船回不了港。你在大廳門口分流，就像奧德修斯喬裝成乞丐回到自己家：沒有人知道你已經準備好了，你只能用做的事證明。
- **上燈塔**：歐律克勒亞說「還撐得住」。史詩裡是老乳母摸到疤、認出主人；這裡反過來，**是你用身體評估，認出她說不出口的病**。這是全作最重要的一個「認出」。
- **點燈**：孟拓提著油壺爬完最後一段樓梯，歸航燈亮了。停在外海的船一艘一艘開回來。
- **十二斧之試**（新，見下一節）：真正的「英雄歸來」放在這裡。

## 三、玩法：三個新系統，和現有系統怎麼對上

現有的系統一個都不拆，只換名字、換說法：

| 現有系統 | 在歸航記裡叫什麼 | 改什麼 |
|---|---|---|
| 航海圖 | 霧海圖 | 島名；終章加歸航線 |
| 請教老醫生 | 問長老 | 只換名字。底線照舊：只看你做了什麼，不看答案 |
| 港城回音 | **歸鄉的消息** | 史詩裡有一整段在講誰回到了家、誰沒有。病人的近況就是他的「歸鄉」 |
| 霧潮夜 | **海神的風暴** | 只換名字 |
| 辨霧燈 | **明眼燈** | 史詩第十九卷，雅典娜提著金燈照亮大廳。燈只跟著你判斷對的線索亮 |
| 資格試煉 | **試弓** | 平常的練習照舊；正式的那一場，見下面的十二斧之試 |

### 新系統一：劫的回顧——「這一劫，你有沒有被困住？」

每一張委託結束後，回顧多一段：這一位病人是哪一劫，以及**根據你這一場實際做的事**，判斷你有沒有掉進那一劫的陷阱。不用新的病例內容，全部用現有的紀錄判斷：

| 劫 | 怎麼判斷你被困住了 | 資料從哪裡來 |
|---|---|---|
| 獨眼巨人 | 下診斷時，「還要排除」一個都沒選 | 推理板 |
| 風袋 | 選了錯的處置請求 | 回報的請求 |
| 斯庫拉 | 主訴的問題沒有問到「怎麼開始、怎麼變」那幾題 | 問過的題目 |
| 日神之牛 | 選了錯的處置請求，或沒提出檢查就結案 | 回報、檢查 |
| 賽蓮 | 選了錨定在錯誤解釋的那一句摘要 | 摘要的選擇 |
| 擲石巨人 | 病人該通報卻沒有通報（或拖到變差） | 安全行動 |
| 野豬之疤 | 四肢的評估沒做，或動手前沒說明 | 評估紀錄 |
| 卡律布狄斯 | 中途說你最擔心的，跟最後的診斷不同、卻沒有線索支持你改 | 中途的判斷、線索 |
| 忘憂果 | 沒問他最擔心什麼 | 問過的題目 |
| 喀耳刻 | 生命徵象沒量就下診斷 | 生命徵象紀錄 |
| 卡呂普索 | 生活和擔心那幾題沒問 | 問過的題目 |
| 冥府 | 診斷錯，或該排除的危險診斷沒有線索 | 推理板、線索 |

沒掉進去，就寫「你過了這一劫」；掉進去了，就寫是哪一個動作讓你困住、下一次怎麼過。**不計分**，只是讓你把十二個陷阱的名字記住。這也是航海圖上的另一層進度：過了的劫，島邊會多一個小記號。

### 新系統二：十二斧之試——真正的「英雄歸來」

史詩的高潮：奧德修斯拉開那張沒人拉得開的弓，一箭穿過排成一列的十二把斧頭。**十二把斧頭剛好是十二個主訴。**

- 現在的資格試煉（抽一位病人、真實倒數 15 分鐘、沒有提示、不掛燈）照舊，叫「試弓」。
- 終章走完之後，大廳多一排十二把斧頭。**在某個主訴的試弓裡及格一次，那一把斧頭就亮。**試弓抽題時，優先抽還沒亮的主訴。
- 十二把都亮了，播最後一段：「英雄歸來」。孟拓把紀錄板交給你，新的見習上船。
- 這跟口試直接對齊：口試是抽題，你不知道會抽到哪一個主訴。十二把斧頭全亮，代表十二個主訴你都在沒有提示、真實時間的條件下通過過一次。

### 新系統三：吟遊詩人的開場

每一章開頭，由費民（眠墨）用史詩的口吻起頭，一兩句就好，例如：

> 「說吧，記事的人，說那位見習的故事：她在霧海上漂流，見過許多人的病，認出了許多藏在霧裡的形狀。」

史詩感主要靠這種開場、固定稱號、和偶爾一個長比喻；**對話本身維持現在的短句**，不寫成文言或翻譯腔。上一輪的回饋是「用字看不懂」，所以這條很重要：神話的味道放在大廳，病室裡一個字都不加。

## 四、執行計畫

## 五、我不確定、要你決定的事

**病人要不要也改成希臘名字。**我的建議是**不改**。理由有三個：病人是港城裡的普通人，史詩的名字放在神話那一層（公會、長老、劫影），病人保留中文名，兩層才分得出來；口試考的是臺灣的病人，學員看到「駱松，70 歲，退休的老船長」比看到一個希臘名字更像真的；Threads 已經發出去的每日一案用的是中文名，改了會斷掉。如果你還是想改，四十九個名字可以一次換，病例的內容不用動。

**名字要照抄荷馬，還是取音但不照抄。**上面的表大多是「取音、借性格」，例如岑禾叫孟拓，不是直接叫門托；歐律克勒亞、聶思、雅蕾、娜希則是直接用原名。照抄的好處是認得出來，壞處是熟悉神話的人會拿原典的劇情對照，覺得對不上。我建議**長老和忍冬用原名（他們的性格本來就是借原典的），其他人取音**，你看要不要全部統一。

**遊戲名和網址。**我建議遊戲名改成**《霧脈公會：歸航記》**，保留「霧脈公會」：網址（mist-guild）、Threads 帳號（@mistguild.np）和已經發出去的貼文都不用動。如果要完全換名，網址和帳號會斷，已經分享出去的連結也會失效。

**主角是男是女。**奧德修斯是男性，但我們的六位主角有男有女。我把主角的角色寫成「歸航的人」，不綁性別；史詩引子裡的「她／他」照玩家選的那一位換。

**劫的對應有三個比較勉強**：斯庫拉配腹痛（「只盯著一點」）、喀耳刻配疹子（「外表變了」）、冥府配感覺異常（「你不先開口，他們不說話」）。其他九個我覺得很貼。這三個你如果有更好的想法，告訴我。

**考前要做到哪裡。**口試是 12 月 5 日，剩兩週。第一階段只動大廳和圖鑑的文字，不碰病室，風險低；但它會讓已經熟悉遊戲的人看到一大堆新名字。我的建議是**考前做第一階段，第二、三階段考後再做**。如果你覺得考前不要再動任何東西，整個計畫往後移也可以，#12 照樣先合併。

**臨床的部分**：劫的陷阱是我依臨床推理的常見錯誤寫的，跟病例本身一樣，要請臨床老師看過。
