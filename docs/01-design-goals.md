## 1. 一句話

> 一款給 NP 學員的像素風自走棋：每一局是一個 OSCE 考站。玩家面對一個主訴，派出棋子把它一層層拆開，直到看清楚背後的診斷。

## 2. 核心比喻

| 自走棋 | 這款遊戲 |
|---|---|
| 一局 | 一個 OSCE 考站，也就是一個主訴 |
| 敵人 | 被面紗包住的主訴，背後藏著診斷 |
| 敵人的血量 | 面紗的層數。每拆掉一層，露出一條線索 |
| 棋子 | 蒐集資訊的動作：問診、理學檢查、檢驗檢查 |
| 羈絆 | 臨床上成套的架構。例如問診的 LQQOPERA 八項、理學檢查的視觸叩聽 |
| 勝利 | 面紗揭開，看清診斷 |

面紗的層次可以對應臨床診斷推理的步驟：蒐集資料 → 用一句話描述問題 → 列出鑑別診斷 → 確立診斷（Bowen, 2006）。這是階段 2 要細談的事，這裡只先確認方向對得上。

## 3. 目標

「來源」欄：✅ 你說過的；🆕 你這次提的；❓ 我的假設，要你確認。

| # | 目標 | 來源 |
|---|---|---|
| G1 | 對象是 NP 學員 | ✅ |
| G2 | 主題是 NP OSCE：從一個主訴出發，拆解到診斷 | 🆕 |
| G3 | 玩法是自走棋：派出棋子，棋子自己行動 | ✅ |
| G4 | 美術是像素風 | 🆕 |
| G5 | 要做成可以發表的研究 | ✅ |
| G6 | 贏的條件是面紗被揭開 | 🆕 |
| G7 | 學習重點是臨床推理：該問什麼、該查什麼、先後順序、怎麼從線索收斂到診斷 | ❓ |
| G8 | 一個主訴是一份資料，之後可以一直加新的主訴，不用改程式 | ❓ |
| G9 | 用瀏覽器就能玩，手機和課堂投影都可以 | ❓ |
| G10 | 一局 10–15 分鐘，和一個考站的長度差不多 | ❓ |

像素風對我們的條件很有利：沒有專職美術也做得出風格一致的畫面，檔案小、手機跑得動，也不會有黏土人的問題。3D 那條路就不再往下走。

## 4. 這個概念最大的風險

**「自走」可能讓玩家變被動。** 如果把所有棋子都派上場，面紗就自己掉下來，那玩家沒有練到推理，只是在看動畫。

我建議把下面兩條寫進設計原則（❓，等你決定）：

1. **揭開的是線索，診斷要玩家自己下。** 面紗拆到一定程度，玩家要說出診斷和鑑別診斷，說對才算贏。這也比較像真的 OSCE。
2. **線索要改變下一步的選擇。** 前一回合露出的線索，應該讓玩家想換一批棋子。這就是「依假設去蒐集資料」，而不是亂槍打鳥。把檢查全開一輪要付出代價（時間或資源）。

## 5. 怎樣算成功

都是 ❓，數字要你來定。

| 面向 | 指標（草案） |
|---|---|
| 學得到 | 玩過之後，臨床推理或 OSCE 相關的表現比玩之前好 |
| 想玩 | 沒人要求的情況下，多數學員會主動再挑戰一個主訴 |
| 會玩 | 不用人教，學員能自己完成第一個主訴 |
| 可信 | 每個主訴的內容通過臨床專家審查 |

## 6. 限制與不做的事

| 項目 | 現況 | 來源 |
|---|---|---|
| 人力 | 你加上我，沒有專職美術和工程 | ❓ |
| 時程 | 不知道 | ❓ |
| 預算 | 不花錢買素材或服務 | ❓ |

第一版不做（全部 ❓）：玩家對戰、帳號系統、多國語言、技術操作類的考站（例如實際操作技術），以及診斷之後的處置。處置可以留到之後當第二階段，先前 sepsis 的 bundle 設計到時候用得上。

## 7. 設計原則

之後每個決定都拿這幾條來檢查。全部 ❓：

1. **玩法就是教材**：要贏就得照臨床推理的方式做，不能靠跟臨床無關的技巧過關。
2. **玩家自己下診斷**：遊戲揭開線索，不替玩家做結論。
3. **臨床正確不打折**：每條線索和每個診斷都有出處，簡化的地方要明講。
4. **一個考站的時間玩得完**。

## 8. 要請你回答的問題

這一輪的三個：

1. **這是取代原本的 sepsis 方向嗎？** 還是 sepsis 變成其中一個主訴背後的診斷（例如「發燒合併意識改變」）？
2. **面紗揭開就直接贏，還是玩家要自己說出診斷才算贏？** 我建議後者，理由在 §4。
3. **你要對應哪一種 OSCE 考站？** 一站多久、評分表有哪些項目（問診、身體檢查、鑑別診斷、處置、溝通…）。還有，第一個主訴你想做哪一個？

上一輪還沒回答、之後仍然需要的：目標衝突時誰優先；在哪裡用、有沒有期限；有沒有其他人一起做。
