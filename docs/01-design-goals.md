## 1. 一句話

> 一款給 NP 學員的像素風回合制遊戲，是 CDSS 臨床推理訓練系統的遊戲版：每一關是一個主訴，玩家照臨床推理的步驟一回合一回合把它拆開，最後自己提出鑑別診斷。

## 2. 和 CDSS 的對應

遊戲沿用 CDSS 的步驟、用詞和分類方式，學員在兩邊學到的是同一套架構。

| CDSS 的步驟 | 遊戲裡 |
|---|---|
| 選主訴 | 選關卡。主訴被面紗包住 |
| 系統選擇 | 決定往哪些系統查 |
| 問診（LQQOPERA） | 問診回合：每問一個面向，揭開一條線索 |
| 身體評估（視診、觸診、叩診、聽診） | 身體評估回合：每做一項，再揭開一條線索 |
| 鑑別診斷 | 面紗揭開後，玩家自己提出鑑別診斷 |
| 回饋與總結 | 結算：哪些該問沒問、哪些該查沒查 |

| 沿用的東西 | 說明 |
|---|---|
| 用詞 | 「身體評估」「LQQOPERA」「鑑別診斷」等，照 CDSS 的詞彙表 |
| 分類 | 科別（內科、外科）、系統（心血管、呼吸、腹部、神經…）、難度（初、中、高） |
| 案例類型 | 典型案例和陷阱案例（看起來像 A，其實是 B） |
| 兩種模式 | 練習（有提示、即時回饋）和 OSCE（計時、結束才看結果） |

### 兩者的分工（❓ 我的假設）

| | CDSS | 這款遊戲 |
|---|---|---|
| 形式 | 和 AI 虛擬病人對話，完整演練 | 回合制選擇，快速反覆練 |
| 需要 AI | 要 | 不用，規則固定 |
| 適合的時機 | 正式練習、模擬考 | 暖身、複習、零碎時間 |

## 3. 玩法：建議改成回合制

你提的回合制，我認為比自走棋更適合，建議就這樣定。

| | 自走棋 | 回合制 |
|---|---|---|
| 玩家什麼時候做決定 | 開打前排好陣容，之後看棋子自己動 | 每一回合都要選下一步 |
| 和臨床推理的關係 | 容易變成看動畫 | 每一步都是「接下來該問什麼、查什麼」 |
| 和 CDSS 的對應 | 要另外設計 | 步驟可以一對一對上 |
| 考站的時間壓力 | 不容易表現 | 每個動作花時間，問不完，逼玩家挑重點 |
| 製作難度 | 高（要做自動戰鬥和平衡） | 低 |

回合制會少掉自走棋的商店和站位。「湊齊一套有加成」可以留下來，例如 LQQOPERA 八個面向問齊，或身體評估照正確順序做完。

## 5. 兩件要先講清楚的事

**案例不能直接搬。** CDSS 的案例是研究工具，有些是保留給測驗用的，學員先在遊戲裡看過就等於曝光。而且這個 repo 是公開的，標準答案放進來等於公開。我的建議是遊戲的病例**全部另外寫**，只沿用格式。要不要共用、共用哪些，由你決定。

**遊戲和 CDSS 研究的關係。** 如果同一批學員會同時用到兩者，遊戲可能影響 CDSS 研究的結果，也可能需要另外的倫理審查。這要由你和指導教授決定。

我對 CDSS 的專案只有讀取，沒有改任何東西；這份文件也沒有寫進它的案例內容或研究細節。

## 6. 怎樣算成功

都是 ❓，數字要你來定。

| 面向 | 指標（草案） |
|---|---|
| 學得到 | 玩過之後，問診和身體評估的完整度、鑑別診斷的正確率比之前好 |
| 想玩 | 沒人要求的情況下，多數學員會主動再挑戰一關 |
| 會玩 | 不用人教，學員能自己完成第一關 |
| 可信 | 每一關的內容通過臨床專家審查 |

## 8. 設計原則

全部 ❓：

1. **玩法就是教材**：要贏就得照臨床推理的方式做。
2. **和 CDSS 說同一種語言**：步驟、用詞、分類都一致。
3. **玩家自己下診斷**：遊戲揭開線索，不替玩家做結論。
4. **臨床正確不打折**：每條線索和每個診斷都有出處。
5. **幾分鐘一關**。

## 9. 要請你回答的三個問題

1. **玩法就定回合制嗎？**
2. **遊戲的病例怎麼來？** 全部新寫（我的建議），還是 CDSS 有哪些案例可以拿來用？
3. **遊戲和 CDSS 是什麼關係？** 獨立的作品，還是 CDSS 研究的一部分、給同一批學員用？這會決定研究怎麼設計，也決定這個 repo 要不要改成不公開。
