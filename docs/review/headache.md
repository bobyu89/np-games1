# 審查清單：頭痛（篤篤鳥）

這份檔案是程式從病例檔產生的（`npm run review`），不要手改。怎麼審、共用的設計和文獻在 [README.md](README.md)。

**症影的說明**：頭痛的症影。停在人的頭上，一下一下地啄。多半只是吵；有幾種啄法，是在報信。

## 四個真身

同一個主訴底下可能的四類問題。這個分法是遊戲的骨架，請先看分得合不合理。

| 真身 | 燈籠上的字 | 說明 | 有哪位病人 | 審查 |
|------|---|---------------------|---------|------|
| 原發性頭痛 | 原 | 頭痛本身就是病：偏頭痛、緊縮型頭痛。 | 喬芸（C05A） | ☐同意 ☐要改 |
| 顱內出血 | 血 | 血管破了：蜘蛛膜下腔出血、腦出血。 | 魏葵（C05B） | ☐同意 ☐要改 |
| 中樞感染 | 炎 | 腦膜或腦在發炎：腦膜炎、腦炎。 | 還沒有 | ☐同意 ☐要改 |
| 顱內壓升高 | 壓 | 裡面多了東西在佔位置：腫瘤、慢慢積起來的血塊。 | 還沒有 | ☐同意 ☐要改 |

## C05A｜又是那一種痛｜喬芸

| 項目 | 內容 |
|------|---------------------------|
| 主訴（症影） | 頭痛（篤篤鳥） |
| 真身（這一關的答案） | 原發性頭痛。頭痛本身就是病：偏頭痛、緊縮型頭痛。 |
| 病人 | 喬芸，29 歲，女，公會帳房的書記 |
| 類型 | 示範 |
| 地點 | 公會的病室 |
| 穩不穩定 | 穩定：這位病人不會變差，敲值班鐘算過度通報 |

| 照理想的打法 | 100 分、達成、模擬時間約 18 分鐘 |

**玩家一開始讀到的**

> 喬芸，29 歲，公會帳房的書記。
>
> 從今天中午開始，左邊的頭一跳一跳地痛，吐了一次。這種痛她從十幾歲就有；這一次，是趕月底的帳、兩天沒睡好之後來的。
>
> 她自己走進來，一手遮著眼睛，問能不能把燈調暗一點。

**讀完要想的三個問題**：最危險的可能是什麼？　頭痛的人，哪幾句話、哪幾個發現是紅旗？　如果紅旗都沒有，我要怎麼跟她說？

### 7. 回顧裡寫給玩家的話

- 這一關的重點不是找到病，是有憑據地說「不是危險的那幾種」。紅旗一面一面查過，才能歸檔。

### 7. 回顧裡寫給玩家的話

- 這一關照考站的順序走。真實的情境裡，雷擊樣的頭痛加上頸部僵硬，一進門就要叫人。提早敲鐘不扣分。
- 有偏頭痛的人，一樣會得別的病。最重要的那句話是她自己說的：「這一次不一樣。」
- 血壓高在這裡可能是結果，不是原因。要不要降、降到多少，由醫師決定。
- 電腦斷層如果正常、懷疑還是很高，醫師會評估要不要做腰椎穿刺。這一位的斷層已經看得到出血。
