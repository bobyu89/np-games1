# 審查清單：頭痛（篤篤鳥）

這份檔案是程式從病例檔產生的（`npm run review`），不要手改。怎麼審、共用的設計和文獻在 [README.md](README.md)。

**圖鑑上的說明**（遊戲的世界觀，不是臨床內容）：頭痛的症影。停在人的頭上，一下一下地啄。多半只是吵；有幾種啄法，是在報信。

## 四個診斷

同一個主訴底下可能的四類問題，玩家要在這四個裡面選最可能的、排除其他的（遊戲的圖鑑裡把它們叫做「真身」，病室裡一律說「診斷」）。這個分法是遊戲的骨架，請先看分得合不合理。

| 診斷 | 畫面上的字 | 說明 | 有哪位病人 | 審查 |
|------|---|---------------------|---------|------|
| 原發性頭痛 | 原 | 頭痛本身就是病：偏頭痛、緊縮型頭痛。 | 喬芸（C05A） | ☐同意 ☐要改 |
| 顱內出血 | 血 | 血管破了：蜘蛛膜下腔出血、腦出血。 | 魏葵（C05B） | ☐同意 ☐要改 |
| 中樞感染 | 炎 | 腦膜或腦在發炎：腦膜炎、腦炎。 | 賀楓（C05C） | ☐同意 ☐要改 |
| 顱內壓升高 | 壓 | 裡面多了東西在佔位置：腫瘤、慢慢積起來的血塊。 | 季蘭（C05D） | ☐同意 ☐要改 |

### 7. 回顧裡寫給玩家的話

- 這一關的重點不是找到病，是有憑據地說「不是危險的那幾種」。紅旗一面一面查過，才能歸檔。

### 7. 回顧裡寫給玩家的話

- 這一關照考站的順序走。真實的情境裡，雷擊樣的頭痛加上頸部僵硬，一進門就要叫人。提早敲鐘不扣分。
- 有偏頭痛的人，一樣會得別的病。最重要的那句話是她自己說的：「這一次不一樣。」
- 血壓高在這裡可能是結果，不是原因。要不要降、降到多少，由醫師決定。
- 電腦斷層如果正常、懷疑還是很高，醫師會評估要不要做腰椎穿刺。這一位的斷層已經看得到出血。

### 7. 回顧裡寫給玩家的話

- 這一關的危險不是幾分鐘之內的事，所以不用敲值班鐘。但影像今天就要做，不能再「觀察兩個禮拜」。
- 「顱內壓升高」底下不只腫瘤。年紀大、跌倒過、吃抗凝血藥的人，要想到慢慢積起來的硬腦膜下血塊。她沒有外傷，也沒有吃那一類的藥。
- 腦裡有佔位病灶的時候，腰椎穿刺是危險的。所以先做影像。
- 壞消息由誰說、什麼時候說、誰陪著聽，都要先想好。影像出來之前，不替她猜結果。
