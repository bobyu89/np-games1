# 審查清單：喘（風箱蛙）

這份檔案是程式從病例檔產生的（`npm run review`），不要手改。怎麼審、共用的設計和文獻在 [README.md](README.md)。

**圖鑑上的說明**（遊戲的世界觀，不是臨床內容）：喘的症影。肚子像風箱一樣一鼓一縮，卻怎麼也吸不滿。同樣是喘，問題可能在心臟、在氣管、在肺，或是突然出的事。

## 四個診斷

同一個主訴底下可能的四類問題，玩家要在這四個裡面選最可能的、排除其他的（遊戲的圖鑑裡把它們叫做「真身」，病室裡一律說「診斷」）。這個分法是遊戲的骨架，請先看分得合不合理。

| 診斷 | 畫面上的字 | 說明 | 有哪位病人 | 審查 |
|------|---|---------------------|---------|------|
| 心因性 | 心 | 心臟打不出去，水積回肺裡：心衰竭、肺水腫。 | 駱松（C02A） | ☐同意 ☐要改 |
| 氣道阻塞 | 氣 | 氣管變窄，氣吐不出去：慢性阻塞性肺病或氣喘的急性發作。 | 霍樟（C02B） | ☐同意 ☐要改 |
| 肺部感染 | 炎 | 肺泡被發炎的東西佔住：肺炎。 | 柯蒲（C02C） | ☐同意 ☐要改 |
| 突發急症 | 急 | 一下子就喘起來：氣胸、肺栓塞。 | 岳楊（C02D） | ☐同意 ☐要改 |

### 7. 回顧裡寫給玩家的話

- 這一關照考站的順序走。真實的情境裡，量到血氧 86% 就會先處理、先叫人，不會等整套問完。提早敲鐘不扣分。

### 7. 回顧裡寫給玩家的話

- 這一關照考站的順序走。真實的情境裡，突然喘起來、一邊聽不到呼吸音的人，會先叫人、先接上監測。提早敲鐘不扣分。
- 「突發急症」底下有兩個病。小腿不腫不痛、沒有久臥或長途旅行，讓肺栓塞比較不像；一邊聽不到呼吸音、敲起來特別響，指向氣胸。
- 戒菸很重要，他自己也知道。等他能好好呼吸的時候再談，他才聽得進去。
