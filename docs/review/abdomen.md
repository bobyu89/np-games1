# 審查清單：腹痛（腹痛蟹）

這份檔案是程式從病例檔產生的（`npm run review`），不要手改。怎麼審、共用的設計和文獻在 [README.md](README.md)。

**圖鑑上的說明**（遊戲的世界觀，不是臨床內容）：腹痛的症影。把一條繩子在肚子裡打了結，越扯越緊。結打在哪裡、怎麼打的，每一次都不一樣。

## 四個診斷

同一個主訴底下可能的四類問題，玩家要在這四個裡面選最可能的、排除其他的。這個分法是遊戲的骨架，請先看分得合不合理。

| 診斷 | 畫面上的字 | 說明 | 有哪位病人 | 審查 |
|------|---|---------------------|---------|------|
| 膽囊與膽道 | 膽 | 右上腹：膽結石卡住、膽囊發炎。 | 方苓（C03A） | ☐同意 ☐要改 |
| 胰臟與胃 | 胰 | 上腹到左上腹：胰臟炎、消化性潰瘍。 | 龔椿（C03C） | ☐同意 ☐要改 |
| 闌尾 | 闌 | 右下腹：闌尾炎。常常從肚臍附近開始痛。 | 邵棠（C03B） | ☐同意 ☐要改 |
| 大腸憩室 | 憩 | 左下腹：憩室炎。 | 鄔桃（C03D） | ☐同意 ☐要改 |
