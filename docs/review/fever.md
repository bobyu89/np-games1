# 審查清單：發燒（餘燼蜥）

這份檔案是程式從病例檔產生的（`npm run review`），不要手改。怎麼審、共用的設計和文獻在 [README.md](README.md)。

**症影的說明**：發燒的症影。背上的炭一明一滅。它只告訴你「燒起來了」，不告訴你火是從哪裡燒起來的。

## 四個真身

同一個主訴底下可能的四類問題。這個分法是遊戲的骨架，請先看分得合不合理。

| 真身 | 燈籠上的字 | 說明 | 有哪位病人 | 審查 |
|------|---|---------------------|---------|------|
| 呼吸道 | 肺 | 火在肺裡：肺炎、支氣管的感染。 | 還沒有 | ☐同意 ☐要改 |
| 泌尿道 | 尿 | 火在腎臟和膀胱：腎盂腎炎、泌尿道感染。 | 溫荷（C04A） | ☐同意 ☐要改 |
| 皮膚與軟組織 | 膚 | 火在皮膚底下：蜂窩性組織炎、傷口感染，最怕往深處燒。 | 涂柏（C04B） | ☐同意 ☐要改 |
| 非感染 | 非 | 不是細菌點的火：藥物、腫瘤、免疫的毛病、血栓。 | 還沒有 | ☐同意 ☐要改 |

## C04A｜不是著涼｜溫荷

| 項目 | 內容 |
|------|---------------------------|
| 主訴（症影） | 發燒（餘燼蜥） |
| 真身（這一關的答案） | 泌尿道。火在腎臟和膀胱：腎盂腎炎、泌尿道感染。 |
| 病人 | 溫荷，34 歲，女，碼頭補網的女工 |
| 類型 | 示範 |
| 地點 | 公會的病室 |
| 穩不穩定 | 穩定：這位病人不會變差，敲值班鐘算過度通報 |
| 審查狀態 | 未審查 |
| 照理想的打法 | 100 分、達成、模擬時間約 18 分鐘 |

**玩家一開始讀到的**

> 溫荷，34 歲，碼頭補網的女工。
>
> 三天前開始發燒、全身痠痛。藥鋪說是著涼，給了退燒的藥粉。昨天起右邊的腰一陣一陣痛；今天早上冷到全身發抖，量到 39 度。
>
> 她自己走進來，臉紅紅的，右手撐著後腰。

**讀完要想的三個問題**：最危險的可能是什麼？　發燒的人，身上有哪幾個地方可能藏著火？　哪幾樣東西變了，就表示她不穩定？

| 生命徵象 | 血壓 | 心跳 | 呼吸 | 血氧 | 體溫 |
|---|---|---|---|---|---|
| 一開始 | 112/70 | 106 | 20 | 98% | 38.9 |

### 7. 回顧裡寫給玩家的話

- 這一關照考站的順序走。發燒的病人，生命徵象要先看：血壓掉了、意識變了、呼吸很快，就不是慢慢問的時候。
- 「著涼」是太早下的結論。發燒加上一個「局部」的症狀（腰痛、小便痛），就從那個局部去找。
- 這一關的四盞燈沒有包括肚子裡的感染和腦膜炎。真的在找發燒的源頭時，這兩處也要想到：所以評估裡有腹部，也有頸部僵硬。
